FORTE

Task-Adaptive Force Capability Optimization for Mobile Manipulators

A task-oriented whole-body optimization framework that adapts robot force capability to the physical requirements of manipulation tasks.

Overview

FORTE optimizes the whole-body configuration of a mobile manipulator while preserving a desired end-effector trajectory. Instead of maximizing force capability everywhere, the framework adapts the required capability to the task, leaving redundancy available for other objectives such as manipulability, joint-limit avoidance, smoothness, and base motion.
